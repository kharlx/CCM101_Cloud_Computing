# Cloud Provider Service Comparison Matrix

This document compares the main cloud services offered by the top three public cloud platforms: AWS, Azure, and GCP.

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 / EBS | Azure Blob Storage / Managed Disks | Cloud Storage / Persistent Disk |
| **Networking** | Amazon VPC | Azure Virtual Network (VNet) | Cloud VPC |
| **Identity and Access Management (IAM)** | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

---

## Guide Questions & Analysis

**1. Which cloud provider offers the broadest range of services? Explain your answer.**  
AWS has the widest variety of services because it was the very first major cloud platform in the market. Since they started way earlier than everyone else, they had more time to build, test, and add tons of tools for almost every IT need.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**  
I recommend Microsoft Azure for companies already using Microsoft software. Azure connects smoothly with Windows Server, Active Directory, and Office tools, and it usually saves companies money through their existing Microsoft licenses.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**  
Google Cloud Platform (GCP) is famous for AI, Machine Learning, and Kubernetes. Since Google actually created Kubernetes and spends huge resources on AI research, GCP runs container apps like GKE and smart AI tools like Vertex AI really well.

**4. What similarities did you observe among the three cloud providers?**  
All three platforms provide the same core essentials: virtual servers, scalable storage drives, and secure private networks. They also use strict IAM roles for access control and charge users through a simple pay-as-you-go setup.
