# Laboratory 02 Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?
I think Compute is the most important component because it serves as the brain of the cloud environment. Without compute resources like CPU and RAM, applications cannot process data, run code, or execute system tasks. While storage and networking are essential, they exist mainly to support the applications running inside the compute instances.

## 2. How does Linux support cloud computing?
Linux supports cloud computing by providing a lightweight, stable, and highly secure operating system. Most cloud servers and virtual machines run on Linux distributions because they are open-source, use fewer system resources, and offer strong command-line tools for automated server management.

## 3. Why is technical documentation important before deploying infrastructure?
Technical documentation is important because it serves as a clear blueprint for the entire team before building anything. It helps prevent configuration errors, ensures team members understand system specs, and makes troubleshooting much easier. Proper documentation also makes future scaling and maintenance smooth and organized.

I also learned how to map physical hardware specs directly into core cloud concepts, compare major cloud providers, and design a simple architecture diagram using Excalidraw.
