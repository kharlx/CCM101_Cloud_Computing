# Laboratory 05: The Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on deploying an open-source, S3-compatible Object Storage server using MinIO inside a Docker container. The activity covers the theoretical differences between Block, File, and Object storage, demonstrates containerized deployment using environment variables, and showcases cloud object management (bucket creation and object uploading) through a web-based administration console.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server (MinIO) using Docker.
- Access cloud services via web interface using port forwarding.
- Create a storage bucket and upload objects (files) to the cloud.
- Document cloud storage operations using Markdown.
- Expand a professional GitHub Cloud Computing Portfolio.

## Tools Used

- **KillerCoda Playground**: Ubuntu / Docker Environment
- **MinIO**: High-performance, S3-compatible Object Storage server
- **Docker**: Containerization engine for service deployment
- **Git & GitHub**: Version control and portfolio documentation
- **Markdown**: Technical documentation format

## Skills Learned

- Configuring environment variables (`-e`) for root administrative credentials in Docker containers.
- Mapping multiple container ports to host interfaces (`9000` for API, `9001` for Console).
- Creating cloud storage buckets and managing unstructured object data via web consoles.
- Evaluating cloud storage architectures for web application scenarios.
