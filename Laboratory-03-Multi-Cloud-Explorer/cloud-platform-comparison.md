## 2. Platform Analysis Questions (Checkpoint 3)

### 1. Which cloud provider offers the broadest range of services?
AWS offers the broadest and deepest range of services, encompassing over 200 fully featured capabilities globally. Its market pioneer advantage allowed it to establish the most comprehensive catalog of cloud infrastructure tools available today.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides unmatched native integration with existing Microsoft technology stacks such as Active Directory, Windows Server, and Microsoft 365. It allows enterprise organizations to extend their Windows environments seamlessly while utilizing Azure Hybrid Benefit cost savings.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest provider in AI/ML and Kubernetes due to Google's history as the original developer of Kubernetes and its advanced research in artificial intelligence. GCP offers optimized tooling like Google Kubernetes Engine (GKE) and Vertex AI backed by specialized TPU hardware.

### 4. Which cloud platform would you personally choose and why?
I would personally choose AWS due to its immense market share, mature documentation, and industry-standard adoption. Mastering AWS builds a strong technical foundation that easily translates across other cloud environments while maximizing career opportunities.
